# 单样本数据审查工作台

基于 PySide6 的单样本桌面程序，提供数据审查、标签勾画、掩膜投影与投影域重建。源图像始终只读，标签可保存，处理结果单独暂存。

## 启动

需要 Python 3.10 或更新版本。建议在仓库根目录创建虚拟环境并安装依赖：

```powershell
python -m venv .venv-review
.\.venv-review\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m metal_seg_qt
```

Windows 也可以在安装依赖后双击 `start_review.cmd`，或运行 `.\start_review.ps1`。
启动脚本优先使用 `.venv-review`、`.venv`，其次使用当前 Python；也可通过
`.\start_review.ps1 -Python 'C:\path\to\python.exe'` 指定解释器。

其他启动方式：`python review_data.py` 或 `python metal_seg_qt/__main__.py`。
命令行可附带文件或序列文件夹，例如 `python review_data.py "C:\data\sample\proj"`。
本仓库不包含样本数据、模型权重、生成结果或本地环境。

首次打开时，窗口按鼠标所在屏幕的可用区域居中，自动适配 Windows 缩放比例并避开任务栏；鼠标不在有效屏幕时使用窗口所在屏幕。默认尺寸上限为 1680×960，较小屏幕自动缩小，工作区不足时显示滚动条，不再用固定最小尺寸把窗口推到屏幕外。之后手动调整窗口大小或位置、切换页面均保留用户操作。

## 使用

窗口左上角可切换「数据审查」「投影域重建」「标签勾画」三个独立页面。页面切换保留各自的数据与状态，共用本次样本的图像管理；标注与分析不自动替换审查画布。

数据审查界面分为左侧「图像管理」、中间四个画布、右侧「工具」。两侧分割条可调整宽度，中间画布占用剩余空间。重建处理已迁入独立「标签勾画」页。

右侧按「查看与定位」「百分位调窗（测试）」「投影叠加（当前幕布）」「新数据导入参数」分为四个折叠块，默认收起。标题整行可点击，使用加大加粗字体和青色高亮边框，展开后标题颜色同步变化。「查看与定位」收纳投影绑定、清除标记、全部适应、一键清空与几何定位；收起只隐藏控件，保留当前设置。

1. 将**同一个样本**的原始投影、归一化 PNG、掩膜等文件或序列文件夹拖入左侧列表，或直接拖到画布。左侧导入的数据会依次放入空画布。
2. 从左侧拖动数据条目到画布，随时替换当前显示。双击条目也可放入当前选中的画布（青色边框）。同一组数据可以放入多个画布。**正在显示的数据会持续高亮，并列出对应画布编号**；选择其他条目不会取消这些高亮，替换或清空画布后状态自动更新。
3. 前三个画布接收投影域；右下角接收重建域。**`slice` / `slices` 文件夹内的数据和 `.slc` 文件自动识别为重建域**，即使拖到投影画布也不会按投影尺寸读取，会放入空的重建画布。其他数据按目标画布或右侧「默认数据域」决定归属。
4. 勾选「投影联动绑定」后，参与「联动」的投影画布同步切层、十字定位、矩形框、缩放、平移和适应窗口；底部滑块也可统一切层。取消某个画布的「联动」或全局开关后可独立操作。重新加入绑定会对齐到其他参与画布。右下角不参与投影联动，窗宽窗位始终各自独立。
5. 灰度图使用窗宽、窗位输入框调节；也可在图像上按住右键拖动：水平改窗宽、竖直改窗位。「自动调窗」使用当前层 1%–99% 灰度范围调整明暗和对比度；**有矩形框时只统计框内像素，没有框时使用整层**，切层后保持调窗结果。「适应窗口」调整缩放和平移，让整张图显示在画布内。各画布窗宽窗位独立，包括自动调窗。
6. 左侧选中数据后勾选「二值掩膜」，有限且非零像素显示为白色，零值显示为黑色。RGB 图按原色显示。彩色标签图不要勾选二值掩膜，以保留类别颜色。
7. 换样本时点击「一键清空」。画布、图像列表、缓存、内存映射与尚未完成的导入都会清理；磁盘文件保留。每个画布右上角的 `×` 仅移除该画布上的显示。

图像操作：左键点击显示细十字定位线；按住左键拖动绘制矩形框，松开后保留；再次点击会用新定位点替换旧矩形。开启绑定时，参与联动的投影画布同步显示标记，右下角重建画布独立。标记和视野按图像内相对位置映射，分辨率不同时仍对应同一区域。缺层时不绘制标记，切回有效层后恢复。

点击任意视图后，画布下方坐标旁显示该点的原始像素值（调窗和二值掩膜显示之前）；彩色图显示通道值。切层时更新同一坐标的读数，缺层时提示缺层。悬停在数值上可查看完整原始值、数据类型及 `[N,Y,X]` 坐标；框选不触发取值，清空或更换数据后重置。

左键按下时不立即定位；短按并松开后才确认点击。拖动会直接进入框选，长按后的轻微拖动也可框选，原地长按再松开不会误触发选点。开始框选时清除上一组点/射线定位，只绘制矩形，不在矩形起点叠加十字线。

「清除标记」只清除十字线和矩形。滚轮切层；Ctrl+滚轮缩放；**中键拖动平移**；右键拖动调窗；双击图像适应窗口。`F` 全部适应；`Ctrl+O` 添加文件。

## 百分位调窗（测试）

在右侧展开「百分位调窗（测试）」，点击任一已放置灰度原图的幕布选定目标，再设置上下百分位（默认 1% / 99%，范围 0%–100%，下值必须小于上值）。下百分位对应显示黑点，上百分位对应白点；窗宽为两者之差，窗位为两者平均值。统计值相同时使用窗宽 1，并明确提示。

- 「当前视图」精确统计当前 A、B 或 C 视图的原始有限灰度值；「整组数据（全局）」统计目标数据全部实际帧，得到统一窗宽窗位。切层后保留结果，不随切层自动重算。
- 默认勾选「调整百分位时实时预览」；也可取消后点击「计算并调窗」。结果区列出上下界原始灰度、窗宽、窗位、帧数、有限像素数，文字可以选择复制。开关和参数针对当前选中幕布，左侧列表的条目选择不改变目标。
- 即使开启投影联动，也只调节目标幕布。窗宽窗位不影响统计；矩形框、叠加掩膜均不参与该测试功能。原有画布「自动调窗」仍按 1%–99% 及当前矩形范围工作。
- 二值掩膜、彩色图和重建阈值预览不能使用此功能。缺失当前视图时提示重试；整组统计遇到坏帧或不同 dtype 会明确报错，不静默丢弃文件。NaN/Inf 不参与统计。
- 整组统计在后台运行，可取消，切换目标或清空会使旧结果失效。对 8/16 位整数、布尔和 float16 使用精确直方图；其他数值类型在数据较大时对所有帧分层采样，总预算约 200 万像素，界面明确显示「近似采样」。结果缓存后，更改百分位不重复读取整组文件。修改磁盘源数据后请移除并重新导入。

## 投影掩膜叠加

前三个投影画布顶部增加「叠加」快捷按钮，点击后打开右侧「投影叠加（当前幕布）」折叠块；选中不同画布时切换到各自的设置。工具默认收起，不占用画布空间。先按原方式把原始投影或一组掩膜放入画布作为底图，再展开叠加工具：

1. 在「叠加图像」下拉框中，直接选择图像管理中的**投影域二值掩膜**，选中后立即叠加到当前幕布。下拉列表随数据导入、暂存、移除和属性修改自动更新；新掩膜请先导入图像管理，并确认数据域为「投影」、已勾选「二值掩膜」。悬停下拉选项可查看文件路径。
2. 「彩色填充」将掩膜非零区域着色，背景透明；「掩膜轮廓」只显示一像素内边界。可以选择红、青、黄、紫，并调整不透明度。底图照常独立调窗，掩膜颜色不受调窗影响。
3. 底图也标记为二值掩膜时，可以选择「掩膜差异」：**浅灰为两者共有，橙色为仅底图存在，紫色为仅叠加层存在**。颜色仅表示两张掩膜的关系，不代表哪张正确。工具下方显示当前帧各类像素数；不透明度调到 100% 时完整显示差异颜色。
4. 取消「显示」可以快速对照底图；选择「不叠加」或点击「移除」仅卸下当前叠加层，数据仍在图像管理中。收起工具保留显示状态。替换底图或清空画布时移除该画布的叠加层。

叠加按**真实帧号**匹配，跟随底图切层、缩放、平移和三视图截面。各投影画布独立选择叠加层、模式、颜色和不透明度。两组数据需具有相同图像尺寸、视野和方向；尺寸或帧号完全不匹配时拒绝叠加，不自动缩放、配准或用邻层代替。缺失或异常的掩膜帧只显示底图并提示，不把未知区域算作掩膜差异。左侧列表同时高亮底图和叠加数据；点击图像后的坐标读数同时显示底图原始值与掩膜原始值。

## 每个画布的三视图（检查数据排列）

四个画布默认均显示「原始切片」，需要时从每个画布顶部的下拉框切换到三视图。辅助截面仅在需要时后台读取。只按读取到的数组 `D[N,Y,X]` 重切，不额外翻转、转置或依据 PTM 改变图像排列：

| 视图 | 数组内容 | 方向 |
| --- | --- | --- |
| A 原始切片 / 投影帧 | `D[n,:,:]` | 列 X 向右，行 Y 向下 |
| B 固定行截面 | `D[:,y,:]` | 列 X 向右，层/视角 N 向下 |
| C 固定列截面 | `D[:,:,x]` | 行 Y 向右，层/视角 N 向下 |

重建域的 N 是切片编号，投影域的 N 是投影视角编号。因此投影 B/C 是跨视角截面，不能当作人体的冠状面、矢状面。标签显示数组轴，暂不宣称已经验证了物理方向。

- 主滑块改变 N；B 上方的 `Y=` 和 C 上方的 `X=` 改变截面。也可在 B/C 上滚轮切换其固定坐标。
- 点击任意视图会更新 B/C 辅助截面的蓝色坐标线；A 原始图不再叠加常驻蓝十字。在 B/C 中点击还能选择 N，使 A 跳到相应切片。投影绑定时，前三窗的 X/Y 定位以及对应辅助视图的缩放、平移一起同步。
- 每个画布顶部下拉框可从「三视图」切换到单独的「原始切片」「固定行截面」「固定列截面」放大查看；分割条可调整三个视图的大小。
- 下拉框旁的「放大」按钮会让该画布占满中间四个画布区域，左右侧栏保留；再次点击「还原」或按 `Esc` 回到 2×2 布局。放大/还原保留各画布的数据、当前切片、视图模式和窗宽窗位。
- 同一画布三视图共用窗宽窗位。点击某视图后，「自动调窗」针对该视图（有框时取框内）；右键也可调窗。几何点和射线仍绘制在 A 原始图，B/C 用于检查原始数组排列。
- 横向截面在后台按需读取，状态栏显示读取进度；更改 X/Y 会取消过时任务，一键清空会取消读取。源文件只读，体数据通过文件映射访问，按需使用内存。
- N 按层号递增，普通缺层留黑，坏层在截面状态提示。对跨度极大的稀疏编号仅排列实际层号，避免展开海量空层。图像本身不做插值，三个方向保持原始像素值。

B/C 换截面已增加共享体数据缓存：图像/PRJ/SLC 序列只在首次打开辅助视图时后台读取一次，按原始 dtype 建立临时磁盘缓存；同一数据放在多个画布时共用缓存。后续改变 X/Y 直接从保持打开的内存映射中提取截面，避免重复遍历几百个文件及重复解码。NPY/BIN/RAW 体数据直接复用独立的只读映射，不再复制整份数据。普通 N 切层只读取当前帧并移动辅助视图坐标线，无需重建截面。

首次缓存构建可取消，快速连续切换会续接已完成的缓存进度；新截面准备期间保留上一帧，减少黑屏闪烁。缓存只用于本次会话，移除数据或一键清空后，在后台读者退出时清理，不修改样本文件。临时磁盘不足或图像序列混合不同 dtype 时自动使用原读取方式，避免截断数值。修改磁盘源文件后请移除并重新导入，以重建缓存。


这一模式用于检查当前读入结果，不会自动修正此前几何映射中的坐标约定。

## 重建点与投影射线的几何定位

右侧「几何定位：重建点 / 投影射线」默认开启。将同一样本的重建切片放入右下角、投影放入前三窗后，**在重建图像上单击**，该体素及其在当前各投影角度下的对应位置显示红色十字线。**在投影图像上单击**，则在重建域显示其对应的空间射线路径。左键拖动仍用于画矩形，不会把框选误当成几何选点。

- 红十字使用几何定位；普通二维定位使用青色。建立几何定位后清除普通十字，切换两域时不保留上一组蓝/青色定位线，只显示当前几何标记。单个投影像素对应一条空间射线，深度不唯一；不会将这条射线自动判成某一个三维体素。
- 切换投影层号时，固定三维点按对应 PTM 重新计算，因此关闭投影联动、分别查看不同角度时，三个红十字可以处于不同位置。
- 切换重建切片后，三维选点保持固定；右下角仅在选点原来的那一层显示红十字。再次单击选择新点，或点击「清除标记」清除选点。
- 几何目录自动从当前数据目录及附近父目录查找。需要同一样本的 `proj/PTM.dat`、`proj/cbct_task.xml`，以及重建的 `slice/ImageParam.ini`。文件缺失、目录不匹配、层号越界、投影在探测器背面或视野外时，隐藏对应红十字，并在右侧说明原因。
- 投影处理图必须保留原始探测器的完整视野与方向；支持等比例缩放，不推测裁剪、翻转、转置、拼图或配准关系。重建图像的实际尺寸必须与其 INI 一致。XML 中额外的体积镜像目前不支持。

投影点 → 重建射线的显示约定：

- 点击投影图像后，该角度上的选点显示红色十字。用该帧 PTM 求出焦点和正向空间射线，并裁剪到实际重建体积内。
- **橙色虚线**表示体内三维射线在重建平面上的俯视轨迹，方便观察整条路径；它不表示射线一定在当前切片平面内。
- **红色十字**表示射线与当前切片平面的真实交点。通常空间射线与二维切片只有一个交点；只有共面时才显示**红色实线段**。与当前切片无交点时明确提示，只保留橙色俯视轨迹。
- 拖动重建切片滑块，可以沿各切片查看交点。改变来源投影画布的角度时，射线随之更新；改变其他未绑定画布的角度不改变这条射线。
- 单击重建图像会切回重建点 → 投影点模式。清除标记、移除来源画布或一键清空会清除射线。缺帧、错误几何或射线不穿过重建体积时不保留旧的误导性标记。

反投影使用 `P=[M|p]`，焦点 `C=-M⁻¹p`、方向 `d=M⁻¹[u,v,1]`，得到 `C+t·d (t≥0)`。射线先转换到重建体素坐标，以真实体素边界做线段裁剪，再求当前切片平面交点；不通过三维体素中亮度最大值等启发式猜测深度。

实现先用 INI 的首像素中心、行列方向及体素间距把 `(列, 行, 层号)` 转成 INI 坐标，再转换到 PTM 使用的世界坐标 `(X,Y,Z)`，计算 `[a,b,c] = P @ [X,Y,Z,1]`、`u=a/c`、`v=b/c`。PTM 第 `i` 行对应 `i + Input_Views_Start_Count`。首层与 XML 体积中心在同一坐标系中决定保存层序的正负方向；若无法确定则停止映射。PTM 整数坐标按探测器像素中心解释，绘制时处理半像素偏移。

**Fussen 原生坐标约定**：本项目原生样本的 `ImageParam.ini` 图像/患者坐标与 PTM 设备坐标之间需要 `diag(-1,+1,-1)`，即 X、Z 反向，Y 保持。程序读取 INI 的 `Manufacturer=Fussen` 后应用这一转换，同时用于正投影和反投影；其他来源保持通用坐标约定。坐标转换显示在几何状态提示中。这里变换的是三维坐标，原始图像和三视图数组的排列不变。


坐标定义参考 [DICOM 图像平面位置与方向](https://dicom.nema.org/medical/Dicom/2023c/output/chtml/part03/sect_C.7.6.2.html) 和 [OpenCV 三维投影矩阵说明](https://docs.opencv.org/doc/doxygen/html/d2/d48/group__d__projection.html)。Fussen 转换依据本项目原生样本的实际跨视角核验，不由通用 DICOM 定义直接推断。几何定位尚不能替代使用标定物进行的独立精度验证。

## 数据格式与层号

| 格式 | 读取约定 |
| --- | --- |
| PNG / JPG / BMP / TIFF | 支持单图、图像序列文件夹、RGB/RGBA、16 位灰度和单文件多页 TIFF |
| NPY | 数值灰度数组 `[H,W]` 或 `[N,H,W]`；不读取对象数组，不将最后一维猜测为颜色通道 |
| PRJ | 每个文件一层，按投影尺寸和「其他 Raw dtype」读取 |
| SLC | 每个文件一层，固定按小端 16 位有符号整数 `int16` 读取，尺寸按重建规则确定 |
| BIN / RAW | 每个文件作为连续的 `[N,H,W]` 体数据，层数由文件字节数推导 |

- 文件名末尾的数字作为真实层号，例如 `proj_2.png` 与 `proj_10.png` 按 `2、10` 排序，并可以与同层号 PRJ 绑定。文件末尾数字必须唯一。
- 没有统一末尾数字的序列按文件名自然排序，从 0 编号；NPY、BIN/RAW、多页 TIFF 也从 0 编号。界面不自动推断不同命名方式之间的层号偏移，导入前应统一编号。
- 缺少目标层时显示「层号缺失」，不使用邻层替代。不同序列长度可以不同。
- 多选拖入的同目录图像文件形成一组序列；不同处理结果应放在不同文件夹。一个文件夹只放一种处理结果。NPY、BIN、RAW 每个文件各为一组。
- 拖入文件夹时，同时扫描当前目录和其一级子文件夹中的图像，各子文件夹作为独立序列进入左侧管理列表；当前目录已有图像也不会跳过子文件夹。不继续递归更深目录，重复拖入的同一序列不会重复添加。空文件夹和不含支持格式的文件夹不会作为图像条目加入列表。

## 原始数据参数

右侧「新数据导入参数」默认折叠，点击标题可展开/收起，收起时保留参数设置。内容较多时在右侧工具栏内滚动，左侧图像管理始终独立。

投影默认是 **768 × 768、小端 uint16**。投影和重建的宽、高分别设置。勾选「优先读取附近 XML 的尺寸」时，查找当前目录的 `cbct_task.xml`、同级 `proj/cbct_task.xml` 和父目录的同名文件。

- 投影域：使用 `Sensor_Vertical_Size × Sensor_Horizontal_Size`。
- 重建域开启「自动识别重建尺寸」时，先读取附近 `ImageParam.ini` 的 `Height / Width`，其次读取 XML 的 `Volume_Horizontal_Size`。均无有效尺寸时，单层 SLC 按文件字节数和 `int16` 的每像素 2 字节推导方形边长，因此可读取 600×600、800×800 等不同尺寸。
- **800 × 800 只是重建手动输入的初始值，不是固定假设**。非方形或无可用元数据的重建数据，可取消「自动识别重建尺寸」，填写「重建 宽 × 高」；BIN/RAW 体数据不能仅靠总字节数确定切片尺寸，须提供元数据或手动尺寸。PNG、TIFF、NPY 使用文件自带的实际尺寸。
- **`slice` / `slices` 文件夹中的原始数据及 `.slc` 文件固定按小端 `int16` 读取**，保留负值，不受「其他 Raw dtype」影响；整目录混合导入时也分别应用该规则。PNG、TIFF、NPY 保留文件自带的数据类型。
- 其他 float16/float32 原始掩膜或重建数据须在导入前选择对应「其他 Raw dtype」。「二值掩膜」只是显示方式，不替代正确的 dtype。尺寸来源会在左侧详情中显示。
- 不同分辨率的掩膜如果与原始 XML 尺寸不同，应取消 XML 选项，填写其实际宽、高。
- 文件字节数不匹配会报错。若 dtype 字节数相同但含义不同，程序无法从文件大小判定，请确认数据来源。
- 导入参数只影响之后导入的数据；已导入 Raw 数据需要移除并重新导入才能更改尺寸或 dtype。更改左侧数据域只改变画布归属。

## 标签勾画与掩膜投影

原「重建处理」已改为独立 `LabelingWidget`，入口是左上角「标签勾画」。[详细设计与交互说明](metal_seg_qt/LABELING_DESIGN.md)。

1. 在本页下拉框选择已导入的重建数据，点击「打开 / 继续勾画」。原图只读；已有二值重建掩膜可以作为数据源继续编辑，其前景会成为标签 1。
2. 标签表默认仅显示一行金属，需要其他结构时再添加标签。三个正交切面共享同一份三维标签；定位、画笔、橡皮、多边形平铺为按钮，覆盖规则使用单选按钮。每个幕布下方固定切片滑块，兼容真实层号；平移滚动条隐藏，直接用中键拖动平移，Ctrl+滚轮缩放。
3. 多边形点击放置顶点，拖动顶点修正；点首点、双击、Enter（含数字键盘）、右键或「闭合并填充」按钮均可闭合填充。Backspace 删除末点，Esc 放弃未提交操作。切层后可用 Ctrl+V 粘贴上一轮廓，再调整接受。每次笔画、轮廓或阈值应用都可 Ctrl+Z 撤销、Ctrl+Y 重做。
4. 「阈值辅助」按原始灰度预览黄色候选，选择「应用当前切面」或「应用整组」才写入当前标签，遵守覆盖与锁定规则。预览不参与输出；取消后台阈值操作会回滚本次修改。
5. 用「保存标签文件」保存 `.npz`，包含多标签体、标签定义、来源路径和真实层号，可重新载入。切换页面与数据源保留本次会话的勾画；关闭、清空或移除含未保存标签的数据时提示保存。
6. 左下方固定的输出区可选择「当前标签」或「勾选标签合并」，生成重建域二值掩膜，或直接生成全部角度的投影域掩膜。结果带版本号，加入图像管理后可通过投影叠加下拉框选择比较。

投影使用同样本 XML/PTM/INI，继承真实层号与此前校准的 Fussen 坐标转换，沿射线穿过标签前景体素输出 `uint8` 的 `0/1`。重建缺层或几何缺失时不能生成投影，仍可勾画、保存标签和导出重建掩膜。投影计算复用 `consistency/consistency_filter.py`，需要 `numba`，首次计算会后台编译。

标注底图、标签与撤销差分保存在临时磁盘文件中，最近 100 次体素编辑可撤销。加载、阈值应用、文件保存与投影在后台执行且可取消。图像管理中的生成结果仍是会话暂存；永久标签文件需要主动保存。本版按数组 N/Y/X 显示正交切面，不自动重采样为患者解剖方向，不包含三维表面渲染或跨层自动插值。

## 投影域重建：支持率与冲突分析

这是左上角独立的「投影域重建」页面，用于把未经一致性处理的投影二值掩膜转换为三维支持率体、可调阈值的包络，并检查其重投影与输入之间的差异。该体数据表达掩膜轮廓的几何约束，不是 CT 衰减值重建。

### 输入与计算

1. 在「输入掩膜」下拉框中直接选择图像管理中的投影域二值掩膜。列表随导入、移除及属性修改同步更新，悬停选项查看来源路径。也可点击「添加文件 / 添加文件夹」导入后在下拉框选择；本页与页面标签不接收拖拽导入。
2. 直接添加的数据按投影掩膜导入；Raw 的 dtype 可在本页添加前选择，尺寸沿用数据审查的 Raw/XML 导入参数。PNG/TIFF/NPY 保留自带 dtype。计算逐帧校验仅含 `0 / 1 / 255 / 65535`，普通灰度图、概率图或错误 dtype 不会被静默二值化。
3. 几何自动读取同样本 `proj/PTM.dat`、`proj/cbct_task.xml` 和 `slice/ImageParam.ini`，也可手动指定几何样本目录。投影目录中的同名 INI 可能描述探测器，重建网格优先取 `slice` 的 INI。不要求先加载灰度重建切片。
4. 选择空间采样并点击「计算三维支持率」。默认 **×4 预览**，可改为 ×2 或 ×1 原生网格。采样保留整个物理体积的范围和之前校准的 Fussen 坐标约定；粗网格可能遗漏细小结构，界面始终标出采样倍数，选点同时显示原始网格的近似坐标和真实 XYZ(mm)。原生网格的计算量及临时空间显著增加。

每个网格体素完整统计前景票数 H 和有效视角数 V，支持率 `S=H/V`。投影在视野外、探测器背侧及未导入的帧不计背景票；V=0 显示未知。输入按真实帧号匹配 PTM 并排序，支持缺帧及保持完整视野的等比例缩放，不推测裁剪、翻转或拼接。

调整一致性阈值 τ 与最少有效视角数后，包络由 `V>0 且 V>=min_views 且 H/V>=τ` 得到。支持率已缓存，改变阈值只更新包络和重投影。当前视角优先计算，其余输入视角在后台继续；旧阈值任务取消，迟到结果不覆盖新参数。未导入的视角不生成虚构的比较结果。

### 布局与交互

- 上方三个画布：输入掩膜、当前包络重投影、彩色差异图。缩放、平移、框选和视角联动。浅灰表示共同前景，橙色表示输入前景未被包络解释，紫色表示重投影超出输入前景。
- 下方左侧：支持率热图、二值包络、热图加包络边界或有效视角覆盖率；支持 XY/XZ/YZ 截面切换。XY 可选同样本灰度重建叠加观察，该参考图不参与计票。
- 重建幕布标题旁的「放大」可让该幕布占满本页图像和曲线区域，左侧工具保留；点击「还原」或按 `Esc` 恢复原布局与曲线分割比例。切换保留当前切片、图像缩放、标记和分析结果；页面切换保留放大状态，清空分析时恢复普通布局。
- 下方右侧：逐视角差异曲线、所选体素的投票状态条、沿空间射线的支持率曲线。橙色差异比例的分母为输入前景数量；紫色的分母为重投影前景数量。分母为零时不虚构百分比，缺帧曲线留断点。
- 点击体素：显示网格与原始近似坐标、物理位置、前景/背景/有效票数，在投影中显示对应位置。投票条中青色为前景、橙色为背景、灰色为视野外/无效；点击某个状态跳到对应帧。
- 点击投影：显示裁剪到重建体积内的真实射线及当前截面的交点，并按 DDA 遍历经过的体素绘制支持率曲线。点击曲线选择经过体素，跳转截面并查看投票，不自动猜测唯一深度。
- 框选投影区域后，可仅统计框内的逐视角差异；点击差异曲线跳转相应帧。只有当前一组定位标记，开始框选会清除上一次点/射线。

### 暂存与生命周期

「支持率体 → 暂存图像管理」生成重建域 float32 连续数据（0–1，未知为 NaN）；「包络掩膜 → 暂存图像管理」生成重建域 uint8 二值掩膜；「重投影掩膜 → 暂存图像管理」生成投影域 uint8 二值掩膜。包络和投影记录生成时的阈值、最少有效视角及采样倍数。采样结果保留自身物理网格，可以在数据审查中继续定位和进行掩膜投影。

结果单独进入图像管理，原始输入保留；同一支持率体重复暂存会复用条目。切换页面保留结果，「清空本页分析」只清理分析状态，已经暂存的数据保留。「取消后台计算」保留已完成的支持率体。数据审查的一键清空同时取消所有页面的任务并释放数据；后台读者持有独立资源直到退出，临时映射随最后使用者清理。

支持率不是金属概率，差异也不等同于真值误差；分割、几何、离散化和阈值均可能导致差异，投影吻合也不能证明三维形状唯一。

体绘制、灰度 CT 重建及 DICOM / NIfTI 等读取留待后续实现。程序不计算对数归一化，直接加载现有处理结果。
